Pick the portal you're syncing. We'll save the URL, open a secure browser window, and you sign in like normal. RouteReady never sees your password.

Using a different portal?

1 · Sign in to your portal

Open the portal in a managed browser window and sign in like normal. We save your session automatically the moment you finish — no extra click needed. Your session stays on this machine — encrypted in the OS keychain.

2 · Verify session

Headless probe of the DSP portal home. Confirms the cached session is still valid before we run a sync.

3 · Download a report

Paste a report URL. The app navigates with your saved portal session and saves whatever file it gets. Test it on a plain file URL first (e.g. a public CSV), then point it at the Amazon reports console.

4 · Scheduled downloads

Run named report pulls on an interval, unattended. The app reuses the saved portal session, opens a headless browser, fires the download, and writes the file to disk. Skipped silently when there's no portal session — sign in again and the loop picks back up.

5 · Scrape applicants from the portal

Walks the candidate list, opens each row, clicks reveal buttons, scrapes name / email / phone into a CSV. The first time you set one up, hit Record — a real browser window opens and a pink toolbar walks you through clicking each thing you want scraped. We save those picks as a recipe; runs replay them. When Indeed shuffles their layout, hit Record again — no app reinstall.

6 · AI agent crawler new

Instead of recording a click-path, you give the agent a plain-English goal. It reads the live page, decides what to click itself, finds the records you asked for, and (optionally) uploads them straight into RouteReady.
