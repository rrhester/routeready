Welcome — let's sign you in

Pick the portal you're syncing. We'll save the URL, open a secure browser window, and you sign in like normal. RouteReady never sees your password.

Using a different portal?

1 · Sign in to your portal

Open the portal in a managed browser window, sign in with your usual login + MFA, then click I'm signed in. Your session stays on this machine — encrypted in the OS keychain.

2 · Verify session

Headless probe of the DSP portal home. Confirms the cached session is still valid before we run a sync.

3 · Download a report

Paste a report URL. The app navigates with your saved portal session and saves whatever file it gets. Test it on a plain file URL first (e.g. a public CSV), then point it at the Amazon reports console.

4 · Scheduled downloads

Run named report pulls on an interval, unattended. The app reuses the saved portal session, opens a headless browser, fires the download, and writes the file to disk. Skipped silently when there's no portal session — sign in again and the loop picks back up.
