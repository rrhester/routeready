Getting started

Five quick steps and you're pulling data.

Run the installer you just downloaded, point RouteReady at the portal you're syncing, and pull your first report. Takes about three minutes.

Your download is starting — check your browser's download bar.
1

Run the installer

Open the file your browser just downloaded — pick your OS for the exact steps.

Double-click RouteReady-Desktop.exe in your Downloads folder. Windows will show a blue "Windows protected your PC" warning because the installer isn't code-signed yet.

  • Click More info (small link under the warning text).
  • Click Run anyway.
  • The installer finishes silently and launches the app.

Open RouteReady-Desktop.dmg, then drag RouteReady Desktop into the Applications folder. The first time you launch it, macOS will say "Apple cannot check it for malicious software".

  • Open System Settings → Privacy & Security.
  • Scroll to the bottom — you'll see a note about RouteReady Desktop was blocked.
  • Click Open Anyway, then confirm with your password / Touch ID.

Note: this build is for Apple Silicon (M1/M2/M3/M4) only. If you're on an Intel Mac, let us know — we'll cut an x64 build.

Open the ChromeOS Files app, double-click RouteReady-Desktop.deb in your Downloads folder. The Linux installer GUI opens — click Install, wait ~30 seconds, and "RouteReady Desktop" shows up in your launcher.

  • First time only: you'll need Crostini (the ChromeOS Linux environment) turned on. Settings → About ChromeOS → Developers → Linux development environment → Set up if you haven't.
  • If double-click doesn't work, right-click the .deb and choose Install with Linux.

Make the AppImage executable and run it:

  • Open a terminal in the folder where the file landed.
  • chmod +x RouteReady-Desktop.AppImage
  • ./RouteReady-Desktop.AppImage
2

Tell RouteReady which portal you're using

The app opens to three numbered cards. In section 1, paste the Portal URL for whatever you're syncing — the field saves automatically as you type.

Indeed https://employers.indeed.com/ Amazon DSP https://logistics.amazon.com/

Using something else? Paste any portal URL — the app's portal-agnostic.

3

Sign in once

Click Open portal & sign in. A second browser window opens at the portal you configured. Sign in with your normal credentials and MFA — RouteReady never sees or stores your password.

Back in RouteReady Desktop, click I'm signed in. The status pill in the top-right flips to Session saved and your session is encrypted to disk via the OS keychain.

Optional: hit Probe portal in section 2 to confirm the cached session is working.

4

Download a report

In section 3, paste the URL of the report or file you want to grab. Two flavors:

  • Direct file URL — leave the click selector blank. The app navigates with your saved session, the file downloads automatically.
  • Page URL + click selector — useful when the file sits behind an Export button. In Click selector, paste a CSS selector for the button (e.g. button[aria-label="Export"]).

Click Download. The file lands in your OS Downloads folder (or wherever you picked) and shows up in the Recent downloads list with a Show in folder link.

5

That's it

From now on, the app reuses the saved session — no re-signing in unless it expires. Run a sync whenever you want fresh data. Coming soon: scheduled syncs, automatic upload into RouteReady, and named report shortcuts.
